## Задание 1. Методы
### Задача 6. Большая буква
**Текст задачи:** Дана сигнатура метода: `public boolean isUpperCase(char x);`  
**Полный текст задачи:** Необходимо реализовать метод таким образом, чтобы он принимал символ `x` и возвращал `true`, если это большая буква в диапазоне от 'А' до 'Z'.  
**Алгоритм решения:** Использовать встроенный метод `Character.isUpperCase(x)` в комбинации с проверкой попадания ASCII-кода символа в диапазон латинского алфавита `x >= 'A' && x <= 'Z'`.

### Задача 7. Диапазон
**Текст задачи:** Дана сигнатура метода: `public boolean isInRange(int a, int b, int num);`  
**Полный текст задачи:** Метод принимает левую и правую границу диапазона. Необходимо реализовать метод так, чтобы он возвращал `true`, если `num` входит в указанный диапазон. Отношение `a` и `b` заранее неизвестно.  
**Алгоритм решения:** Проверить, кто из границ меньше: `a` или `b`. Если `a < b`, проверить условие `num >= a && num <= b`. В противном случае проверить `num <= a && num >= b`.

### Задача 8. Делитель
**Текст задачи:** Дана сигнатура метода: `public boolean isDivisor(int a, int b);`  
**Полный текст задачи:** Необходимо реализовать метод так, чтобы он возвращал `true`, если любое из принятых чисел делит другое нацело.  
**Алгоритм решения:** Проверить остаток от деления с помощью оператора `%`. Вернуть результат условия `(a % b == 0) || (b % a == 0)`.

### Задача 9. Равенство
**Текст задачи:** Дана сигнатура метода: `public boolean isEqual(int a, int b, int c);`  
**Полный текст задачи:** Метод должен возвращать `true`, если все три полученных числа равны.  
**Алгоритм решения:** Сравнить все три переменные между собой в одном логическом выражении: `a == b && b == c`.

### Задача 10. Многократный вызов
**Текст задачи:** Дана сигнатура метода: `public int lastNumSum(int a, int b);`  
**Полный текст задачи:** Метод считает сумму цифр двух чисел из разряда единиц. Необходимо последовательно сложить пять чисел.  
**Алгоритм решения:** В методе вернуть `a % 10 + b % 10`. В `main` в цикле `for` последовательно получать новое число и передавать в метод текущую сумму и новое число, обновляя результат.

## Задание 2. Условия
### Задача 6. Тройная сумма
**Текст задачи:** Дана сигнатура метода: `public boolean sum3(int x, int y, int z);`  
**Полный текст задачи:** Вернуть `true`, если два любых числа из трех можно сложить так, чтобы получить третье.  
**Алгоритм решения:** Проверить три комбинации: `x + y == z` или `x + z == y` или `y + z == x`.

### Задача 7. Двойная сумма
**Текст задачи:** Дана сигнатура метода: `public int sum2(int x, int y);`  
**Полный текст задачи:** Вернуть сумму чисел. Если сумма попадает в диапазон от 10 до 19 включительно, то вернуть 20.  
**Алгоритм решения:** Найти `sum = x + y`. Через конструкцию `if` проверить попадание `sum` в диапазон `[10, 19]`. Если да — вернуть 20, иначе `sum`.

### Задача 8. Возраст
**Текст задачи:** Дана сигнатура метода: `public String age(int x);`  
**Полный текст задачи:** Возвращает строку с числом и словом: "год", "года" или "лет" с учетом правил русского языка.  
**Алгоритм решения:** Проверить исключения (от 11 до 14). Затем через оператор `% 10` выбрать правильное окончание для 1 ("год"), от 2 до 4 ("года") и остальных случаев ("лет").

### Задача 9. День недели
**Текст задачи:** Дана сигнатура метода: `public String day(int x);`  
**Полный текст задачи:** Возвращает строку, обозначающую день недели (от 1 до 7). Вместо `if` использовать `switch`.  
**Алгоритм решения:** Написать `switch(x)`, где каждому `case` от 1 до 7 соответствует возвращаемая строка с днем недели, а блоку `default` — строка "это не день недели".

### Задача 10. Вывод дней недели
**Текст задачи:** Дана сигнатура метода: `public void printDays(String x);`  
**Полный текст задачи:** Метод выводит на экран переданный день и все последующие до конца недели, используя `switch`.  
**Алгоритм решения:** Преобразовать строку в номер дня через `switch`. Если день корректный, запустить цикл `for` от этого номера до 7, выводя на экран результат метода `day(i)`.

## Задание 3. Циклы
### Задача 6. Одинаковость
**Текст задачи:** Дана сигнатура метода: `public boolean equalNum(int x);`  
**Полный текст задачи:** Вернуть `true`, если все знаки числа одинаковы.  
**Алгоритм решения:** Найти последнюю цифру (`x % 10`). Запустить цикл `while(x > 0)`. Если текущая последняя цифра не равна эталонной, вернуть `false`. Иначе отсечь цифру (`x /= 10`). 

### Задача 7. Квадрат
**Текст задачи:** Дана сигнатура метода: `public void square(int x);`  
**Полный текст задачи:** Вывести на экран квадрат из символов `*` размером `x` на `x`.  
**Алгоритм решения:** Использовать два вложенных цикла `for` от 0 до `x`. Во внутреннем выводить `*`, во внешнем делать перенос строки.

### Задача 8. Левый треугольник
**Текст задачи:** Дана сигнатура метода: `public void leftTriangle(int x);`  
**Полный текст задачи:** Вывести на экран треугольник из `*` с выравниванием по левому краю высотой `x`.  
**Алгоритм решения:** Внешний цикл от 1 до `x` включительно. Внутренний цикл от 0 до `i`, где выводится `*`.

### Задача 9. Правый треугольник
**Текст задачи:** Дана сигнатура метода: `public void rightTriangle(int x);`  
**Полный текст задачи:** Вывести треугольник, выровненный по правому краю.  
**Алгоритм решения:** Внешний цикл от 1 до `x`. Внутри него два цикла: первый выводит `x - i` пробелов, второй выводит `i` звездочек `*`.

### Задача 10. Угадайка
**Текст задачи:** Дана сигнатура метода: `public void guessGame();`  
**Полный текст задачи:** Метод генерирует число от 0 до 9, считывает ввод и запускается, пока пользователь не угадает.  
**Алгоритм решения:** Использовать `java.util.Random` для генерации числа. Запустить бесконечный цикл `while(true)` с чтением ввода, счетчиком попыток и `break` при угадывании.

## Задание 4. Массивы
### Задача 6. Реверс
**Текст задачи:** Дана сигнатура метода: `public void reverse(int[] arr);`  
**Полный текст задачи:** Изменить текущий массив `arr`, записав его задом наперед.  
**Алгоритм решения:** В цикле от 0 до `arr.length / 2` менять местами элементы `arr[i]` и `arr[arr.length - 1 - i]` через временную переменную `temp`.

### Задача 7. Возвратный реверс
**Текст задачи:** Дана сигнатура метода: `public int[] reverseBack(int[] arr);`  
**Полный текст задачи:** Вернуть новый массив, записанный задом наперед.  
**Алгоритм решения:** Создать `res` размера `arr.length`. В цикле присваивать `res[i] = arr[arr.length - 1 - i]`. Вернуть `res`.

### Задача 8. Объединение
**Текст задачи:** Дана сигнатура метода: `public int[] concat(int[] arr1, int[] arr2);`  
**Полный текст задачи:** Вернуть новый массив, состоящий из элементов `arr1` и `arr2`.  
**Алгоритм решения:** Инициализировать массив длиной `arr1.length + arr2.length`. Заполнить его первым массивом в первом цикле `for`, а затем вторым массивом со смещением индекса во втором цикле.

### Задача 9. Все вхождения
**Текст задачи:** Дана сигнатура метода: `public int[] findAll(int[] arr, int x);`  
**Полный текст задачи:** Вернуть массив с индексами всех вхождений `x` в `arr`.  
**Алгоритм решения:** Пройти по массиву, подсчитать количество `x`. Инициализировать массив нужной длины. Пройти по массиву второй раз, записывая индексы совпадений в новый массив.

### Задача 10. Удалить негатив
**Текст задачи:** Дана сигнатура метода: `public int[] deleteNegative(int[] arr);`  
**Полный текст задачи:** Вернуть новый массив со всеми элементами `arr`, кроме отрицательных.  
**Алгоритм решения:** Подсчитать количество элементов `>= 0`. Создать массив этого размера. Вторым циклом `for` скопировать только неотрицательные элементы.
