## Задание 1. Классы

### Задача 1.2. Человек
**Текст задачи:** Создать сущность `Человек`, которая описывается именем (строка) и ростом (целое число). `toString()` возвращает строку вида `"Name, рост: height"`. Создать людей: Клеопатра — 152, Пушкин — 167, Владимир — 189.

**Алгоритм решения:**
1. Объявить класс `Person` с полями `String name` и `int height`.
2. Реализовать конструктор `Person(String name, int height)`.
3. Переопределить `toString()`: вернуть `name + ", рост: " + height`.
4. В `main` создать три объекта `Person` с заданными данными и вывести их на экран.
5. Добавить пользовательский ввод: пользователь может добавить своего человека с проверкой роста (целое число).

---

### Задача 1.3. Имена
**Текст задачи:** Создать сущность `Имя`, описываемую тремя параметрами: Фамилия, Личное имя, Отчество. Любой параметр может быть не задан. `toString()` возвращает традиционное представление без незаданных параметров. Создать: Клеопатра; Пушкин Александр Сергеевич; Маяковский Владимир.

**Алгоритм решения:**
1. Объявить класс `Name` с тремя полями: `surname`, `firstName`, `patronymic`.
2. Реализовать три конструктора:
   - `Name(String firstName)` — задано только личное имя;
   - `Name(String surname, String firstName)` — заданы фамилия и имя;
   - `Name(String surname, String firstName, String patronymic)` — заданы все три.
3. В главном конструкторе нормализовать пустые строки в `null` с помощью тернарного оператора, чтобы незаданные параметры не участвовали в выводе.
4. `toString()` собирает непустые части через пробел в порядке Фамилия → Имя → Отчество.
5. В `main` создать три имени и вывести их. Добавить пользовательский ввод с проверкой обязательности личного имени.

## Задание 2. Объединение сущностей

### Задача 2.2. Человек с именем
**Текст задачи:** Объединить сущности `Человек` (1.2) и `Имя` (1.3) так, чтобы имя задавалось объектом `Name`, а не строкой. Получить:
- Человека с Именем Клеопатра, рост 152;
- Человека с Именем Пушкин Александр Сергеевич, рост 167;
- Человека с Именем Маяковский Владимир, рост 189.

**Алгоритм решения:**
1. Создать **новый** класс `PersonWithName` (не модифицировать существующий `Person`, так как задание требует именно объединения через новый класс).
2. Поля: `Name name`, `int height`.
3. Конструктор `PersonWithName(Name name, int height)`.
4. `toString()` возвращает `name + ", рост: " + height`.
5. В `main` создать три объекта `PersonWithName`, передавая в конструктор объекты `Name` из задачи 1.3.
6. Добавить пользовательский ввод: пользователь вводит фамилию/имя/отчество (можно пропустить), затем рост.

## Задание 3. Графы

### Задача 3.3. Города
**Текст задачи:** Создать сущность `Город` — точку на карте с названием и набором путей к следующим городам. Путь — сочетание `Города` и стоимости поездки. `toString()` выводит название города и список связанных городов в виде `"название:стоимость"`. Реализовать схему с рисунка 2 (A, B, C, D, E, F и связи между ними).

**Алгоритм решения:**
1. Объявить класс `Path` с полями `City city`, `int cost`. `toString()` → `"название:стоимость"`.
2. Объявить класс `City` с полями `String name`, `List<Path> paths`.
3. Конструктор `City(String name)` создаёт пустой список путей.
4. Метод `addPath(City city, int cost)` добавляет путь с проверками:
   - город не `null`;
   - город не сам себя;
   - стоимость не отрицательная;
   - в этот город ещё нет пути (дубликаты запрещены).
5. `toString()` формирует строку вида `"A: B:5, F:1, D:6"`.
6. В `main` создать шесть городов A, B, C, D, E, F и связи согласно рисунку 2:
   - A → B (5), A → F (1), A → D (6);
   - B → C (3);
   - C → D (4);
   - D → E (2);
   - E → F (2);
   - F → B (1).
7. Добавить пользовательский ввод: возможность создать свой город и добавить ему пути к уже существующим, с проверкой дубликатов и отрицательных стоимостей.

## Задание 4. Перегрузка конструкторов

### Задача 4.8. Создаем Города
**Текст задачи:** Изменить сущность `Город` из задачи 3.3. Новые требования:
- Город можно создать, указав только название;
- Город можно создать, указав название и набор связанных городов и стоимостей путей к ним.

**Алгоритм решения:**
1. Добавить в `City` второй конструктор `City(String name, List<Path> paths)`.
2. Внутри конструктора не копировать список напрямую, а перебирать пути и добавлять их через `addPath`, чтобы сработали все проверки (нет дубликатов, нет отрицательных стоимостей).
3. Первый конструктор `City(String name)` делегирует создание городу без путей.
4. В `main` продемонстрировать оба способа:
   - `new City("Москва")` — только с названием;
   - `new City("Тверь", paths)` — с набором путей.
5. Добавить пользовательский ввод: пользователь может создать свой город и выбрать, задавать ли ему пути.

## Задание 5. Работа с числами

### Задача 5.5. Дроби
**Текст задачи:** Создать сущность `Дробь` со свойствами:
- числитель (целое);
- знаменатель (целое);
- создание с указанием числителя и знаменателя;
- `toString()` возвращает `"числитель/знаменатель"`;
- методы сложения, вычитания, умножения и деления с другой дробью или с целым числом.

Результат операции — новая дробь, исходные не изменяются.  
Продемонстрировать: `1/3 * 2/3 = 2/9`, вычислить `f1.sum(f2).div(f3).minus(5)`.

**Алгоритм решения:**
1. Объявить класс `Fraction` с полями `int numerator`, `int denominator`.
2. В конструкторе запретить нулевой знаменатель (выброс `IllegalArgumentException`) и выполнить сокращение через НОД.
3. Реализовать методы:
   - `sum(Fraction)` и `sum(int)` — сложение;
   - `minus(Fraction)` и `minus(int)` — вычитание;
   - `multiply(Fraction)` и `multiply(int)` — умножение;
   - `div(Fraction)` и `div(int)` — деление.
4. Каждый метод возвращает **новый** объект `Fraction`, исходные дроби не изменяются.
5. `toString()` возвращает `"числитель/знаменатель"`.
6. В `main`:
   - создать дроби 1/3, 2/3, 3/4;
   - продемонстрировать все операции;
   - вывести цепочку `f1.sum(f2).div(f3).minus(5)`.
7. Добавить пользовательский ввод с проверкой знаменателя (не ноль) и выводом результатов операций над пользовательскими дробями.

## Демонстрация в главном методе

В `main` реализован дружественный интерфейс:
- меню с пунктами заданий;
- ввод данных через `Scanner`;
- проверка на ввод через `try/catch` и циклы;
- вызов конструкторов и методов классов;
- вывод результатов через `toString()`.

**Вспомогательные методы `Main`:**
- `readInt(Scanner)` — читает целое число с повторным запросом при ошибке;
- `readString(Scanner, String)` — читает непустую строку;
- `readOptionalString(Scanner, String)` — читает строку, допускает пустой ввод;
- `yes(Scanner, String)` — возвращает `true` при ответе «да/yes/y»;
- `readFraction(Scanner, String)` — читает дробь с проверкой знаменателя.
